# Minecraft 巨构设计提示词

完整长期提示词保存在 `E:\巨构提示词.txt`。任何多方块结构生成、修改、重做或导出任务都必须先读取该文件，并以它作为设计与交付依据。

## 当前交付约定

- 每次只制作用户当前指定的一台机器。
- 输出格式固定为 Minecraft 1.20.1 可用的 `.litematic` 文件。
- 文件可以放入本次任务选择的任意合适文件夹，不强制使用 WorldEdit 的 `.schem` 目录。
- 参考环境为 GregTech Odyssey 0.5.6-beta。
- 原游戏目录为：`<path-to-GTO-0.5.6-beta-client>`。
- 旧版 Sponge Schematic v2、`.schem` 和 GregTech Leisure-Enhanced 路径设定均已废止。

## 设计原则

生成结构时仍须遵守原提示词中的机器身份、阶段差异、尺寸控制、细节层次、完整方块限制、真实材料核验、主方块与仓室标记、核心留空、悬浮或底座约束、坐标检查和单机交付流程。用户当次明确要求优先于长期默认规则。

## 文件检查

导出后确认 `.litematic` 可以被 Litematica 读取，区域尺寸、方块调色板、方块状态、坐标范围及必要的实体或方块实体数据一致；确认主方块和 24 个普通钻石矿组成同一平面的连续 5×5 区域。完成后只交付当前机器的结构文件。
